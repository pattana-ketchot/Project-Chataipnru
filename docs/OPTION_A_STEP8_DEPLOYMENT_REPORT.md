## 3. หลักฐานว่าฟีเจอร์ที่ย้ายมาทำงานจริง — ทดสอบด้วย **คณิตศาสตร์** (ไม่ใช่วิทยาการคอมพิวเตอร์)

หน้ารายละเอียดหลักสูตรคณิตศาสตร์แสดง

| ช่อง | ค่าที่ขึ้นจริง | มาจากไหน |
|---|---|---|
| ระดับการศึกษา | ปริญญาตรี | `/api/course-facts` |
| ระยะเวลาศึกษา | 4 ปี | `/api/course-facts` |
| **ค่าเล่าเรียนต่อภาคการศึกษา** | **12,000 บาท** | `/api/course-facts` (ประกาศของคณะ) |
| **เกี่ยวกับสาขา** | "หลักสูตรวิทยาศาสตรบัณฑิต สาขาวิชาคณิตศาสตร์ มุ่งผลิตบัณฑิตให้มีความรู้คู่คุณธรรม…" | **`/api/course-facts` (สกัดจาก มคอ.2)** |
| ค่าใช้จ่ายตลอดหลักสูตร | ไม่ระบุ | ถูกต้อง — หลังบ้านไม่คำนวณให้เพราะต้องเดาจำนวนภาคเรียน |
| คณาจารย์ | "ยังไม่มีข้อมูล" | ถูกต้อง — หลังบ้านไม่มีรายชื่อที่ยืนยันได้ของสาขานี้ จึงไม่ส่งมา **ไม่แต่งชื่อขึ้นเอง** |

ช่อง "เกี่ยวกับสาขา" ของคณิตศาสตร์ **ว่างอยู่ใน Supabase** แต่หน้าเว็บแสดงข้อความจากเอกสารจริงได้
— นี่คือหลักฐานตรงว่าการเติมข้อมูลจาก `/api/course-facts` ทำงานถูกต้อง
