## 1. แถวค่าเทอม

เพิ่มแถว "ค่าเทอม" ต่อจากระยะเวลาเรียน

```
ค่าเทอม   12,000 บาท / ภาคการศึกษา
          ภาคปกติ 12,000 บาท · ภาค กศ.พบ (เสาร์-อาทิตย์) 14,000 บาท
```

ค่ามาจาก `/api/course-facts` ซึ่งอ่านจาก **ประกาศค่าเทอมของคณะ** ไม่ได้ผ่านโมเดล
(เส้นทางเดียวกับที่หน้ารายละเอียดหลักสูตรใช้อยู่) · ไม่มีข้อมูลก็เขียนว่าไม่มีตามจริง

## 2. "ขอปีล่าสุด"

ตรวจคลังเอกสารแล้ว **ปีที่ตารางแสดงอยู่เป็นฉบับล่าสุดของแต่ละสาขาอยู่แล้ว**

| สาขา | ฉบับในคลัง | ที่แสดง |
|---|---|---|
| การจัดการสิ่งแวดล้อมฯ | 2565 (ฉบับเดิมปี 2560 ใช้ชื่อสาขาอื่น) | 2565 |
| การแพทย์แผนไทยประยุกต์ | 2560 · **2565** | 2565 |
| เทคโนโลยีการเกษตรสมัยใหม่ | **2564** (มีฉบับเดียว) | 2564 |
| คณิตศาสตร์ · คอมพิวเตอร์แอนิเมชันฯ | 2564 · **2569** | 2569 |
| วิทยาการคอมพิวเตอร์ · เทคโนโลยีสารสนเทศ | 2561 · **2566** | 2566 |

แต่มี **ความเสี่ยงที่เพิ่งเกิดขึ้นวันนี้**: การเติม `course_id` ให้สาขาเทคโนโลยีการเกษตร
สมัยใหม่ทำให้หน้าเว็บผูกกับ "เล่มนั้น" ตายตัว ถ้าคณะนำฉบับใหม่เข้าคลังภายหลัง หน้าเว็บ
จะยังแสดงฉบับ 2564 ต่อไปโดยไม่มีอะไรบอก ขณะที่สาขาอื่นที่จับคู่ด้วยชื่อจะเลื่อนไปฉบับ
ใหม่เองอัตโนมัติ

จึงแก้ให้ `/course-facts` **เลื่อนไปฉบับล่าสุดของสาขาเดียวกันเสมอ** ไม่ว่าจะเข้ามาทาง
รหัสหรือทางชื่อ — ตัดปีออกจากชื่อเล่มแล้วให้ตัวจับคู่เดิมหาใหม่ (ซึ่งเลือกฉบับล่าสุดและ
แยกระดับปริญญาได้อยู่แล้ว) หาไม่เจอก็คืนเล่มเดิม ไม่คืนค่าว่าง
