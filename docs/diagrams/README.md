# ไดอะแกรมของระบบ (PlantUML)

ซอร์สของไดอะแกรมทั้งหมดเป็นไฟล์ข้อความ `.puml` แก้ได้ทีละบรรทัดและเห็น diff ใน git
ภาพ `.png` / `.svg` สร้างจากซอร์ซเหล่านี้ด้วย `render.sh`

---

## ⚠ ต้อง render ด้วย kroki.io เท่านั้น

ทดสอบเมื่อ 19 ต.ค. 2569 ด้วยไดอะแกรมเดียวกัน ส่งไปสามเซิร์ฟเวอร์

| เซิร์ฟเวอร์ | ผลกับภาษาไทย |
|---|---|
| `plantuml.com` | **กล่องเปล่าทั้งหมด** — ไม่มีฟอนต์ไทยติดตั้ง |
| `planttext.com` | **พังครึ่งเดียว** — พยัญชนะขึ้น แต่สระบน/ล่างและวรรณยุกต์กลายเป็นกล่อง |
| **`kroki.io`** | **ถูกต้องสมบูรณ์** ทุกสระทุกวรรณยุกต์ |

ลองตั้ง `skinparam defaultFontName` เป็น `Tahoma` และ `Sarabun` แล้วทั้งคู่ ไม่ช่วย
เพราะเซิร์ฟเวอร์ไม่มีฟอนต์นั้นอยู่

**ใช้ planttext.com เป็นที่พิมพ์และตรวจไวยากรณ์ได้** แต่ภาพตัวอย่างจะเห็นภาษาไทยเพี้ยน
เวลาจะเอาภาพจริงให้ใช้ kroki

---

## วิธีสร้างภาพ

```bash
bash render.sh          # สร้างทั้ง PNG และ SVG ทุกไฟล์
bash render.sh svg      # เฉพาะ SVG
```

หรือทีละไฟล์

```bash
curl -X POST -H "Content-Type: text/plain" --data-binary @use-case.puml \
     -o use-case.png https://kroki.io/plantuml/png
```

หรือวางเนื้อไฟล์ลงช่องแก้ไขที่ <https://kroki.io> แล้วกดดูผลได้เลย

**แนะนำ SVG สำหรับเอกสารที่ต้องพิมพ์** เพราะซูมแล้วตัวอักษรไม่แตก และไฟล์เล็กกว่ามาก
(เช่น `er.svg` 57 KB เทียบกับ `er.png` 259 KB)

## ข้อควรรู้ตอนแก้ไฟล์

**ขนาดภาพมีเพดาน 4096 px** ถ้าผังกว้างเกินจะถูกตัดขอบขวาโดยไม่มีคำเตือน
สังเกตได้จากความกว้างของภาพที่ออกมาเป็น 4096 พอดี ถ้าเจอให้แก้อย่างใดอย่างหนึ่ง

* ลด `skinparam dpi` (เช่นจาก 100 เป็น 72) — ผังเท่าเดิมแต่ภาพเล็กลง (`er.puml` ใช้วิธีนี้)
* แยกเป็นสองไฟล์ (`er.puml` กับ `er-mko.puml` แยกด้วยเหตุนี้)
* หรือ render เป็น SVG ซึ่งไม่มีเพดานพิกเซล

**ขึ้นบรรทัดใหม่ในป้ายกำกับ** ต้องเขียนเป็น `\n` สองตัวอักษร ถ้าเผลอใส่การขึ้นบรรทัด
จริงลงไปในป้ายของความสัมพันธ์ PlantUML จะฟ้อง `Syntax Error? (Assumed diagram type: class)`

**ไฟล์ต้องเป็น UTF-8 และท้ายบรรทัดแบบ LF** — ถ้าแก้บน Windows แล้วบันทึกเป็น CRLF
บางโปรแกรมแก้ไขจะทำให้ป้ายภาษาไทยเพี้ยน
