# ไดอะแกรมฉบับ Mermaid — สำหรับนำเข้า lucid.app

ซอร์สต้นทางคือไฟล์ `.puml` ในโฟลเดอร์แม่ (`docs/diagrams/`) โฟลเดอร์นี้คือฉบับแปลงเป็น
Mermaid เพื่อวางลง Lucid เนื้อหาเดียวกัน

---

## ทำไมต้องแปลง — Lucid ไม่รับ PlantUML

ตรวจเมื่อ 19 ต.ค. 2569

| สิ่งที่ Lucid รับ | สถานะ |
|---|---|
| **Mermaid** | รับได้ 8 ชนิด — flowchart, sequence, class, state, C4, gantt, ER และอื่น ๆ |
| PlantUML | **ไม่รับ** มีเพียง UML markup ของ Lucid เอง · คำขอให้รองรับ PlantUML ยังเปิดค้างอยู่ |
| ส่งออกจาก Lucid กลับเป็น Mermaid | **ยังไม่มี** คำขอเปิดค้างตั้งแต่ปี 2023 |

ที่มาเป็นกระดานสนทนาของ Lucid ไม่ใช่เอกสารทางการ จึงควรเช็กหน้า help ของ Lucid
อีกครั้งก่อนพึ่งพา

**ทิศทางเดียว** — วาง Mermaid เข้า Lucid ได้ แต่แก้ใน Lucid แล้วเอากลับมาเป็นข้อความไม่ได้
ถ้าจะแก้เนื้อหาในอนาคต ให้แก้ที่ `.puml` หรือ `.mmd` แล้วนำเข้าใหม่ **อย่าถือว่า Lucid
เป็นต้นฉบับ**

## ข้อควรระวังที่เจอจริงตอนแปลง

### 1. บรรทัด `%%` เปล่า ทำให้ Mermaid พังทั้งไฟล์

```
%% คอมเมนต์บรรทัดหนึ่ง
%%                        <-- บรรทัดนี้ทำให้ parse ไม่ผ่าน
%% คอมเมนต์บรรทัดสาม
```

ข้อความที่ได้คือ `Parse error on line 1: %%%%flowchart LR` ซึ่งชี้ไปผิดที่จนหาไม่เจอ
**ต้องมีอักขระต่อท้าย `%%` อย่างน้อยหนึ่งตัว** — ไฟล์ในโฟลเดอร์นี้ใช้ `%% ---`
(ทดสอบแล้วว่า `%% `, `%%-`, `%% .` ผ่านทั้งหมด)

### 2. สิ่งที่ Mermaid ไม่มี จึงย้ายไปอยู่ในคอมเมนต์หัวไฟล์

| PlantUML มี | Mermaid ไม่มี → ทำอย่างไร |
|---|---|
| `legend bottom` | ย้ายไปเป็นคอมเมนต์ `%%` หัวไฟล์ — **ข้อมูลไม่หาย แต่ไม่ปรากฏในภาพ** |
| `== หัวข้อ ==` คั่นลำดับขั้น | ใช้ `Note over` แทน |
| ชนิด use case diagram | วาดเป็น `flowchart` — actor เป็นกล่องขอบมน |
| `package` ใน ER | `erDiagram` ไม่มี subgraph จึงใส่ชื่อ schema หน้าชื่อตาราง (`web_`, `mko_`) |

ถ้าต้องการให้เนื้อหาในบล็อก `legend` ปรากฏในภาพด้วย ต้องเพิ่มเป็นกล่องข้อความใน Lucid
เองหลังนำเข้า

### 3. ชื่อคอลัมน์ใน `erDiagram` ต้องเป็นอักษรละติน

Mermaid อ่าน `type name` เป็นคำเดียว ๆ ข้อความไทยจึงต้องอยู่ในเครื่องหมายคำพูดท้ายบรรทัด

```
uuid id PK "206 แถว"
text role "admin | editor | user"
```

## วิธีนำเข้า Lucid

1. เปิด <https://lucid.app> สร้างเอกสารใหม่
2. หาเมนูนำเข้า Mermaid (อยู่ในกลุ่มเครื่องมือ diagram-as-code / "Import" ของ Lucid)
3. เปิดไฟล์ `.mmd` ด้วย editor ธรรมดา copy **ทั้งไฟล์** รวมบรรทัด `%%` ด้วยก็ได้
4. วางแล้วกดสร้าง
5. ถ้า Lucid แจ้ง syntax error ให้ลองตัดบรรทัด `%%` ทั้งหมดออกก่อน —
   ตัวแปลของ Lucid อาจเก่ากว่าของ kroki

ถ้าภาษาไทยเพี้ยนใน Lucid ให้เปลี่ยนฟอนต์ของเอกสารเป็นฟอนต์ที่มีอักษรไทย
(Lucid เป็นเว็บแอป ใช้ฟอนต์ของเครื่องผู้ใช้ จึงไม่มีปัญหาเดียวกับเซิร์ฟเวอร์ PlantUML)

## วิธี render เองด้วย kroki.io

```bash
curl -X POST -H "Content-Type: text/plain" --data-binary @use-case.mmd \
     -o use-case.svg https://kroki.io/mermaid/svg
```

เปลี่ยน `mermaid` เป็น `plantuml` เมื่อใช้กับไฟล์ `.puml` และเปลี่ยน `svg` เป็น `png`
ถ้าต้องการ PNG — ดู `../render.sh` สำหรับการสร้างทุกไฟล์ในครั้งเดียว
