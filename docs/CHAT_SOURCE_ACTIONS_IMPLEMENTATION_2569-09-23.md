## 2. สิ่งที่ต้องรู้: ภาษาไทยส่งผ่าน header ตรงๆ ไม่ได้

ค่า header ถูกเข้ารหัสเป็น **latin-1** ตอนส่งออก ถ้าใส่ชื่อหลักสูตรภาษาไทยลงไปดิบๆ
จะได้ `UnicodeEncodeError` และ**ทั้งคำตอบล้ม** ไม่ใช่แค่ปุ่มหาย

```
'หลักสูตรวิทยาศาสตรบัณฑิต...'.encode('latin-1')  ->  UnicodeEncodeError
```

จึงหุ้ม `X-Source-Title` และ `X-Source-Programme` ด้วย **base64 ของ UTF-8**
ซึ่งเป็นวิธีเดียวกับที่หน้าเว็บถอด header อยู่แล้ว
`X-Source-Document` กับ `X-Source-Page` เป็น ASCII ล้วน จึงคงรูปแบบเดิมไม่เปลี่ยน

## 4. การ resolve สาขา — ไม่เดาแม้แต่ขั้นเดียว

```
คำตอบ AI
   ↓  (ไม่ได้อ่านข้อความคำตอบเลย)
X-Source-Document  ──> course_documents.course_id ──> courses.title   [FK ในฐานข้อมูล]
   ↓
X-Source-Programme = "หลักสูตรวิทยาศาสตรบัณฑิต สาขาวิชาวิทยาการคอมพิวเตอร์ (พ.ศ. 2566)"
   ↓  (เทียบตรงทุกตัวอักษร ไม่มี fuzzy matching)
programmeLinks.js ──> courseId 20c3ca9c-… + https://sci.pnru.ac.th/program_detail.php?id=10
```

ชื่อที่ไม่อยู่ในตาราง = resolve ไม่ได้ = **ไม่แสดงปุ่มสาขา** ยอมให้ปุ่มหายดีกว่าพาไปผิดสาขา

ชื่อหลักสูตรเก่าก่อนเปลี่ยนชื่อ (เช่น "วิทยาศาสตร์และเทคโนโลยีการอาหาร" → "เทคโนโลยีอาหารฯ")
ใส่ไว้ด้วย โดยยืนยันจาก `_ALIASES` ในหลังบ้านที่มีอยู่แล้ว ไม่ได้จับคู่เอง
