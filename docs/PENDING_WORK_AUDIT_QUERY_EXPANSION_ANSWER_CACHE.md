## 7. สิ่งที่แก้ในเทสต์

`test_คำย่อทุกตัวในตารางคำย่อหาสาขาเจอ`
→ `test_คำย่อทุกตัวหาสาขาเจอ_หรือขอให้ระบุเมื่อไม่มีในตารางค่าเทอม`

เดิมบังคับว่าคำย่อทุกตัวต้องมีแถวค่าเทอม ตอนนี้แยกสองกรณีตามที่ production ทำจริง

| กรณี | เงื่อนไขที่บังคับ |
|---|---|
| มีในตารางค่าเทอม | ต้องหาเจอ และต้องตรงสาขา |
| ไม่มีในตารางค่าเทอม | ต้องหา**ไม่**เจอ และ `tuition.answer()` ต้องขอให้ระบุสาขา |

กรณีที่สองสำคัญกว่าเดิม เพราะมันบังคับไว้ตรง ๆ ว่า **ห้ามไปโดนค่าเทอมของสาขาชื่อคล้ายกัน**
ซึ่งเป็นความเสี่ยงจริงของการจับแบบสับสตริง

ไม่ได้แก้ production logic เพื่อให้เทสต์ผ่าน — hash ยังตรงกับ production ทุกไบต์

## 10. ค้างอยู่ / ข้อจำกัด

### คำถามที่ต้องให้คนยืนยัน

`การจัดการเทคโนโลยีการเกษตรและบริหารทรัพยากรชุมชน (พ.ศ. 2568)` กับ

- ถ้าเป็นสาขาเดียวกัน → ควรเพิ่มชื่อ 2568 ลง `aliases` ใน `backend/app/data/tuition.json`

- ถ้าคนละสาขา → สถานะปัจจุบันถูกต้องแล้ว

ต้องยืนยันจากประกาศคณะ ตัดสินจากชื่อคล้ายกันเพียงอย่างเดียวไม่ได้

### ที่ทำไม่ได้ในรอบนี้

query รายชื่อสาขาจากตาราง `courses` บน production ถูกปฏิเสธ (Production Reads)
จึงใช้รายงาน crawler และผลทดสอบในเครื่องเป็นหลักฐานแทน ซึ่งพอยืนยันว่า 3 สาขานั้นมีจริง
ถ้าต้องการยืนยันกับฐานข้อมูลตรง ๆ ต้องอนุญาต Bash rule สำหรับ ssh/psql

### สาขาที่ยังไม่มีค่าเทอม

`การประกอบอาหารและการบริการอาหาร` และ `สาธารณสุขศาสตร์` ยังตอบค่าเทอมไม่ได้
เพราะประกาศค่าเทอมไม่ครอบ — เป็น **Known Limitation** ไม่ใช่บั๊ก
ห้ามเดาตัวเลขใส่ `tuition.json` ต้องรอประกาศจริง
