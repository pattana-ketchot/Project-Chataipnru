## 1. สิ่งที่พบ — ระบุตาราง แถว และช่องให้ชัด

สแกนตาราง `public.courses` ทั้ง **12 แถว** พบข้อมูลทดสอบ **8 จุด อยู่ในแถวเดียวเท่านั้น**

| รายการ | ค่า |
|---|---|
| ฐานข้อมูล | Supabase (ของหน้าเว็บ) |
| ตาราง | `public.courses` |
| แถว | `20c3ca9c-ff08-4e0a-8685-f782fafdc580` — หลักสูตร **วิทยาการคอมพิวเตอร์** |
| คอลัมน์ | `detail` (ชนิด JSONB) เท่านั้น |

### ช่องที่เป็นข้อมูลทดสอบ (ต้องล้าง)

| ช่องใน `detail` | ค่าปัจจุบัน |
|---|---|
| `about` | `"หฟกหฟกหฟกฟหก"` |
| `faculty[0].name` | `"sadsadsa"` |
| `faculty[0].nameEn` | `"sadsadsa"` |
| `faculty[0].positionTh` | `"sadsadsa"` |
| `faculty[0].positionEn` | `"asdsa"` |
| `faculty[0].email` | `"sdsad@gmail.com"` |
| `highlights[0].title` | `"หก"` |
| `highlights[0].description` | `"หฟก"` |

`faculty` และ `highlights` มีรายการละ **1 รายการ** และทั้งรายการเป็นข้อมูลทดสอบล้วน จึงล้างทั้งรายการได้

### ช่องที่เป็นข้อมูลจริง — **ห้ามแตะ**

| ช่อง | ค่า |
|---|---|
| `detail.level` | `"ปริญญาตรี"` |
| `detail.duration` | `"4 ปี"` |

### ช่องและแถวอื่น

- คอลัมน์ `careers` ของแถวนี้เป็น `[]` อยู่แล้ว ไม่ต้องทำอะไร
- **อีก 11 แถวไม่มีข้อมูลทดสอบเลย** ไม่ต้องแตะ
- คอลัมน์ `title`, `title_en`, `description`, `logo` ไม่ถูกแตะ
- **ไม่ลบทั้งแถว** ลบเฉพาะเนื้อในของ 3 ช่องเท่านั้น

## 3. ทำไมผมลบให้ไม่ได้

ลองเขียนแล้ว **ถูกปฏิเสธ** — ผลคือ *แก้ไป 0 แถว* ไม่มีข้อผิดพลาดใด ๆ ส่งกลับมา
สาเหตุอยู่ในนโยบายความปลอดภัยระดับแถวของ Supabase เอง

```sql
CREATE POLICY "Admins and editors can update courses" ON public.courses
  FOR UPDATE USING (EXISTS (
    SELECT 1 FROM public.user_profiles
    WHERE user_id = auth.uid() AND role IN ('admin','editor') ...
  ));
```

กุญแจฝั่งลูกข่าย (anon key) ที่ผมมี **อ่านได้อย่างเดียว** การแก้ไขต้องล็อกอินเป็นผู้ดูแลระบบก่อน
ซึ่งเป็นบัญชีของคุณ — ผมกรอกรหัสผ่านให้ไม่ได้

**ยืนยันว่าไม่มีการเขียนบางส่วนหลุดไป** ตรวจซ้ำหลังลองเขียนแล้ว ข้อมูลตรงกับที่สำรองไว้ทุกประการ

## 4. คุณทำเองได้ 2 ทาง — เลือกทางใดทางหนึ่ง

### ทาง A (แนะนำ) — Supabase Dashboard → SQL Editor

เปิด Supabase Dashboard → SQL Editor → วางคำสั่งนี้แล้วกด Run

```sql
-- ล้างเฉพาะ 3 ช่องที่เป็นข้อมูลทดสอบ ไม่แตะ level และ duration ไม่ลบทั้งแถว
UPDATE public.courses
SET detail = detail || jsonb_build_object(
      'about', '',
      'faculty', '[]'::jsonb,
      'highlights', '[]'::jsonb
    )
WHERE id = '20c3ca9c-ff08-4e0a-8685-f782fafdc580';
```

ตรวจผลด้วยคำสั่งนี้ — ต้องได้ `about` เป็นข้อความว่าง และทั้งสองรายการเป็น 0

```sql
SELECT title,
       detail->>'about'                 AS about,
       jsonb_array_length(COALESCE(detail->'faculty','[]'::jsonb))    AS faculty_count,
       jsonb_array_length(COALESCE(detail->'highlights','[]'::jsonb)) AS highlights_count,
       detail->>'level'                 AS level,
       detail->>'duration'              AS duration
FROM public.courses
WHERE id = '20c3ca9c-ff08-4e0a-8685-f782fafdc580';
```

ผลที่ควรได้

```
title                  about   faculty_count  highlights_count  level        duration
วิทยาการคอมพิวเตอร์      (ว่าง)        0                0          ปริญญาตรี      4 ปี
```

### ทาง B — ผ่านหน้าแอดมินของเว็บ

1. เข้า `https://stpnru-advisor.duckdns.org/admin` แล้วล็อกอินด้วยบัญชีผู้ดูแลระบบ
2. ไปเมนูจัดการหลักสูตร → เลือก **วิทยาการคอมพิวเตอร์** → แก้ไข
3. ลบข้อความในช่อง **เกี่ยวกับสาขา** ให้ว่าง
4. ลบรายการ **คณาจารย์** ที่ชื่อ `sadsadsa` ออก (มีรายการเดียว)
5. ลบรายการ **จุดเด่น** ที่ชื่อ `หก` ออก (มีรายการเดียว)
6. **อย่าแตะช่องระดับการศึกษา (ปริญญาตรี) และระยะเวลาศึกษา (4 ปี)**
7. บันทึก

รันคำสั่งในไฟล์ `docs/backups/restore_course_detail_20260923.sql` คืนค่าเดิมได้ทั้งหมด

## 5. หลังคุณล้างเสร็จ ระบบจะแสดงอะไร

เมื่อสามช่องนั้นว่าง หน้ารายละเอียดหลักสูตรจะไปดึงจาก `/api/course-facts` มาเติมแทนโดยอัตโนมัติ
ค่าที่ API ตอบอยู่ตอนนี้สำหรับสาขานี้คือ

| ช่อง | ค่าที่จะมาแทน (จากเอกสาร มคอ.2 และประกาศของคณะ) |
|---|---|
| เกี่ยวกับสาขา | "มุ่งผลิตบัณฑิตที่มีความรู้ด้านวิทยาการคอมพิวเตอร์ที่ทันสมัย มีทักษะในการ…" |
| คณาจารย์ | รายชื่ออาจารย์จริงพร้อมความเชี่ยวชาญ (ตรวจแล้วว่านามสกุลปรากฏในเอกสารของหลักสูตรนี้จริง) |
| หน่วยกิต | 130 หน่วยกิต |
| ภาษาที่ใช้ | ภาษาไทย |
| ค่าเล่าเรียนต่อภาค | 12,000 บาท |
| รูปแบบการเรียน | ภาคปกติ 12,000 บาท · ภาคเสาร์-อาทิตย์ 14,000 บาท |
| ชื่อปริญญาอังกฤษ | Bachelor of Science Program in Computer Science |

ส่วน `จุดเด่น` จะไม่แสดงเลย เพราะฝั่งเอกสารไม่มีข้อมูลนี้ — ถูกต้องตามหลัก ไม่แต่งขึ้นมาเอง

ล้างข้อมูล           : ยังไม่ได้ทำ ติดสิทธิ์ RLS ต้องให้คุณทำเอง
