# คู่มือผู้ใช้ Course Compass

## เริ่มต้น

1. เปิดเว็บแล้วกด **เริ่มทำแบบสอบถาม**

   | ใช้งานจาก | ที่อยู่ |
   |---|---|
   | อินเทอร์เน็ต (ใช้ได้ทุกที่ ทุกเครื่อง) | `http://161.118.237.37` |
   | เครื่องที่รันระบบเอง | `http://localhost:3000` |

2. เข้าสู่ระบบ หรือเลือก **ยังไม่มีบัญชี? สมัครสมาชิก**
3. ผู้ใช้ใหม่กรอกชื่อ อีเมล และรหัสผ่านอย่างน้อย 8 ตัวอักษร

## แบบสอบถาม

กรอกระดับการศึกษา สาขา บทบาท เป้าหมาย ทักษะ และความสนใจตามจริง ใช้จุลภาคคั่นหลายทักษะ เช่น `Excel, SQL, การนำเสนอ` เลือกรูปแบบเรียนและระบุงบประมาณได้ ช่องว่างหมายถึงยังไม่จำกัด จากนั้นกด **บันทึกและดูคำแนะนำ**

ควรเขียนเป้าหมายให้เฉพาะ เช่น “เปลี่ยนสายเป็น Data Analyst ภายใน 1 ปี” และระบุข้อจำกัดด้านเวลา รูปแบบ และงบประมาณเพื่อเพิ่มความแม่นยำ

## Chatbot

1. เปิดเมนู **คุยกับที่ปรึกษา**
2. พิมพ์ความต้องการเพิ่มเติม หรือเลือกคำถามตัวอย่าง
3. กดลูกศร ระบบจะแสดงหลักสูตร คะแนนความเหมาะสม และเหตุผล
4. ปรับคำถามแล้วส่งใหม่ได้ เช่น “ออนไลน์ สำหรับผู้เริ่มต้น งบไม่เกิน 5,000 บาท”

คะแนนเป็นตัวช่วยเปรียบเทียบ ควรตรวจราคา ตาราง และเงื่อนไขล่าสุดกับผู้ให้บริการก่อนสมัคร

## ค้นหาและแก้ปัญหา

หน้า **หลักสูตร** ค้นจากชื่อ ผู้ให้บริการ หรือแท็กได้ หากไม่พบให้ลองคำสั้นลง

- “อีเมลหรือรหัสผ่านไม่ถูกต้อง”: ตรวจข้อมูลแล้วลองใหม่
- “ส่งคำขอบ่อยเกินไป”: รอประมาณหนึ่งนาที
- “เชื่อมต่อระบบไม่ได้”: ตรวจ Backend, Database และ Ollama
- Session หมดอายุ: ออกจากระบบแล้วเข้าสู่ระบบใหม่
