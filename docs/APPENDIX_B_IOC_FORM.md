## ส่วนที่ 2 คำชี้แจงสำหรับผู้เชี่ยวชาญ

ขอความอนุเคราะห์ท่านพิจารณาว่า ข้อคำถามแต่ละข้อในแบบสอบถามมีความสอดคล้องกับ
**วัตถุประสงค์ของการประเมิน** หรือไม่ โดยทำเครื่องหมาย ✓ ลงในช่องที่ตรงกับความคิดเห็นของท่าน
ตามเกณฑ์การให้คะแนน 3 ระดับ ดังนี้

| คะแนน | ความหมาย |
|:---:|---|
| **+1** | แน่ใจว่าข้อคำถามนั้น **สอดคล้อง** กับวัตถุประสงค์ของการประเมิน |
| **0** | **ไม่แน่ใจ** ว่าข้อคำถามนั้นสอดคล้องกับวัตถุประสงค์ของการประเมิน |
| **−1** | แน่ใจว่าข้อคำถามนั้น **ไม่สอดคล้อง** กับวัตถุประสงค์ของการประเมิน |

### วัตถุประสงค์ของการประเมินที่ใช้เป็นเกณฑ์พิจารณา

| วัตถุประสงค์ | ข้อคำถามที่เกี่ยวข้อง |
|---|---|
| ข้อ 1 เพื่อประเมินความพึงพอใจด้าน **ความสามารถในการทำงานของระบบ** | ข้อ 1–6 |
| ข้อ 2 เพื่อประเมินความพึงพอใจด้าน **ความง่ายในการใช้งานและการออกแบบส่วนติดต่อผู้ใช้** | ข้อ 7–11 |
| ข้อ 3 เพื่อประเมินความพึงพอใจด้าน **ประโยชน์ที่ได้รับจากการใช้งาน** | ข้อ 12–16 |

# สำหรับผู้จัดทำโครงการ — วิธีสรุปผล (ไม่ต้องส่งให้ผู้เชี่ยวชาญ)

## สูตรคำนวณ

```
        ΣR
IOC = ──────
         n

เมื่อ  IOC = ดัชนีความสอดคล้องระหว่างข้อคำถามกับวัตถุประสงค์
       ΣR  = ผลรวมคะแนนของผู้เชี่ยวชาญทุกท่านในข้อนั้น
       n   = จำนวนผู้เชี่ยวชาญทั้งหมด (ในที่นี้คือ 3 ท่าน)
```

## เกณฑ์การยอมรับ

| ค่า IOC | การพิจารณา |
|---|---|
| **0.50 – 1.00** | ข้อคำถามมีความตรงเชิงเนื้อหา **นำไปใช้ได้** |
| ต่ำกว่า 0.50 | ต้องปรับปรุงข้อความ หรือตัดข้อคำถามนั้นออก |

## ตัวอย่างการคำนวณ

ข้อที่ 3 ได้คะแนนจากผู้เชี่ยวชาญ ดังนี้ ท่านที่ 1 ให้ +1 · ท่านที่ 2 ให้ +1 · ท่านที่ 3 ให้ 0

```
ΣR = 1 + 1 + 0 = 2
IOC = 2 ÷ 3 = 0.67   →  ผ่านเกณฑ์ (≥ 0.50)
```
