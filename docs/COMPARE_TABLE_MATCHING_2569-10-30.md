## 1. จุดที่หนึ่ง — ชื่ออย่างเดียวแยกระดับปริญญาไม่ได้

ตรวจจากข้อมูลจริงบนฐานทดสอบแล้ว **ปัญหานี้มีอยู่จริงและร้ายกว่าที่คิด**

```
courses            หลักสูตรวิทยาศาสตรมหาบัณฑิต สาขาวิชาการจัดการเทคโนโลยีการเกษตรและบริหารทรัพยากรชุมชน (พ.ศ. 2568)
                   หลักสูตรปรัชญาดุษฎีบัณฑิต   สาขาวิชาการจัดการเทคโนโลยีการเกษตรและบริหารทรัพยากรชุมชน (พ.ศ. 2568)
web.site_courses   (ปริญญาโท) การจัดการเทคโนโลยีการเกษตรและบริหารทรัพยากรชุมชน   course_id = NULL
                   (ปริญญาเอก) การจัดการเทคโนโลยีการเกษตรและบริหารทรัพยากรชุมชน  course_id = NULL
```

สองแถวนี้ **ไม่มี `course_id`** การส่งรหัสอย่างเดียวจึงไม่พอ ต้องมีทางถอยที่แยกระดับได้ด้วย

**ที่แก้**

* `/course-facts` รับ `course_id` — ใช้ตรง ๆ เมื่อมี (ค่านี้ `/site/courses` ส่งไปให้อยู่แล้ว)
* รับ `level` แล้วส่งต่อให้ `match_by_title()` ซึ่งแยกระดับปริญญาได้อยู่แล้ว และถือว่า
  **"จับคู่ไม่ได้"** เมื่อชื่อนั้นมีหลายระดับแต่ไม่มีใครบอกระดับ — ไม่เดาให้
* แถวบนเว็บที่ชื่อซ้ำกันหลายแถวไม่ถูกใช้อีก (เดิมหยิบแถวแรกที่เจอ) ถอยไปใช้ตัวจับคู่แทน
* หน้าเปรียบเทียบและหน้ารายละเอียดหลักสูตรส่งทั้ง `course_id` และ `level` ไปด้วย

## 2. จุดที่สอง — `mainDocumentOf()` รับประกันเล่มเต็มไม่ได้

เดิมดูจากคำว่า "ฉบับย่อ" ในข้อความที่แสดง แล้วถ้าไม่เจอก็หยิบ `docs[0]`

* หลังบ้านส่งธง `brief` ของแต่ละเอกสารมาแล้ว ดูจาก **ชื่อไฟล์จริง** และนับคำว่า `brief`
  ที่ใดก็ได้ในชื่อ ไม่ใช่เฉพาะที่ลงท้าย `_brief.pdf`
* หน้าเว็บเลือกเล่มที่ `brief === false` ก่อนเสมอ
* มีแต่ฉบับย่อ → ปุ่มเขียน **"ดูเอกสาร (ฉบับย่อ)"** ไม่อ้างว่าเป็นเล่มเต็ม
* หลังบ้านรุ่นเก่าที่ยังไม่ส่งธง → ปุ่มเขียนกลาง ๆ ว่า "ดูเอกสารของสาขานี้" ไม่เดาเช่นกัน

## 3. ผลตรวจกับข้อมูลจริง (ฐานทดสอบ `course_advisor_test` · อ่านอย่างเดียว)

รัน backend ที่แก้แล้วในคอนเทนเนอร์ชั่วคราว แล้วยิง **HTTP จริง** ไปที่ `/course-facts`
ไม่ได้เรียกฟังก์ชันตรง ๆ และไม่แตะคอนเทนเนอร์ที่ให้บริการอยู่ · ลบคอนเทนเนอร์และไฟล์
ชั่วคราวทิ้งหลังตรวจเสร็จแล้ว

| กรณี | ผล |
|---|---|
| โท + `level=ปริญญาโท` | `วิทยาศาสตรมหาบัณฑิต … (พ.ศ. 2568)` · เอกสาร `agri68_master.pdf` |
| เอก + `level=ปริญญาเอก` | `ปรัชญาดุษฎีบัณฑิต … (พ.ศ. 2568)` · เอกสาร `agri68_phd.pdf` |
| โท / เอก โดยไม่ส่ง `level` (ระดับอยู่ในชื่อแถวเว็บ) | ได้เล่มของตัวเองถูกต้องทั้งคู่ |
| ชื่อสาขาเปล่า ไม่บอกระดับเลย | **`{}` — จับคู่ไม่ได้** ไม่เดาให้ |
| `course_id` ของเล่มโท/เอก (ส่งชื่อผิดมาโดยตั้งใจ) | ได้เล่มตามรหัสทั้งสองกรณี รหัสชนะชื่อ |
| `course_id` ผิดรูป (ไม่ใช่ UUID) | ถอยไปใช้ชื่อ ได้ `คณิตศาสตร์ (พ.ศ. 2569)` ตามปกติ |
| `เทคโนโลยีการเกษตรสมัยใหม่` (แถวเว็บมี `course_id`) | `การจัดการเทคโนโลยีการเกษตรสมัยใหม่ (พ.ศ. 2564)` · 4 ปี · 130 หน่วยกิต |
| `เทคโนโลยีสารสนเทศ` · `วิทยาการคอมพิวเตอร์` (มีทั้งเล่มเต็มและฉบับย่อ) | `it66_brief.pdf brief=True` + `it66.pdf brief=False` · `cs66_brief.pdf brief=True` + `cs66.pdf brief=False` |

### ตรวจบนหน้าเว็บจริงที่ต่อกับ API นี้ (ไม่ใช่สตั๊บ)

เสิร์ฟหน้าเว็บที่ build แล้ว ต่อเข้ากับ backend ตัวเดียวกันผ่าน SSH tunnel แล้วอ่าน DOM

| สิ่งที่เปิด | ผล |
|---|---|
| โท vs เอก (ชื่อเดียวกัน) | คอลัมน์โทขึ้น `ฉบับ พ.ศ. 2568 · วิทยาศาสตรมหาบัณฑิต · อ้างอิงจาก agri68_master.pdf` · คอลัมน์เอกขึ้น `ปรัชญาดุษฎีบัณฑิต · agri68_phd.pdf` — **ไม่ปนกัน** |
| ระยะเวลาเรียนของสองเล่มนั้น | `ยังไม่มีข้อมูลในระบบ` ทั้งคู่ (ตารางข้อเท็จจริงยังไม่มีหลักสูตรบัณฑิตศึกษา) — บอกตามจริง |
| IT vs CS (ทั้งคู่มีฉบับย่อ) | ปุ่ม "ดูเอกสาร" ชี้ไปที่ `it66.pdf` และ `cs66.pdf` (เล่มเต็ม) ไม่ใช่ไฟล์ `_brief` · ตรวจจาก `href` เทียบกับรหัสเอกสารที่ API คืนมา |
| สาธารณสุขศาสตร์ (ไม่มี PDF เลย) | ขึ้น `ยังไม่มีเอกสารให้เปิด` และแถวปีขึ้นเฉพาะชื่อเล่ม ไม่มีปีเพราะชื่อเล่มไม่มีปี |

### กรณีที่ข้อมูลจริงยังไม่มี จึงต้องจำลอง

ฐานทดสอบไม่มีหลักสูตรที่ **มีเฉพาะฉบับย่อ** (มีแต่ "ไม่มีเอกสารเลย" กับ "มีทั้งคู่")
กรณีนี้จึงตรวจด้วยข้อมูลจำลอง: ปุ่มขึ้นว่า `ดูเอกสาร (ฉบับย่อ)` และลิงก์ไปไฟล์ฉบับย่อ
ถูกต้อง — ข้ออื่นทั้งหมดตรวจด้วยข้อมูลจริง

## 4. ที่ยังไม่ได้ทำ

* สองแถวบนเว็บของหลักสูตรโท/เอกยังไม่มี `course_id` — รอบนี้แก้ให้ระบบทนกับเรื่องนี้ได้
  แต่การเติม `course_id` ให้ถูกต้องเป็นงานข้อมูล ไม่ใช่งานโค้ด ถ้าเติมแล้วจะแม่นขึ้นอีกชั้น
* ไม่มีชุดทดสอบอัตโนมัติของ `/course-facts` — รอบนี้ยืนยันด้วยการยิง API จริงบนฐานทดสอบ
  ตามที่สั่ง ถ้าต้องการให้กันการถอยหลังระยะยาว ควรเพิ่มชุดทดสอบที่ใช้ฐานทดสอบนี้
