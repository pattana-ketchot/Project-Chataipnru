## 1. สิ่งที่แสดง (ต่อจากแถวระยะเวลาเรียน)

```
ค่าเทอม   12,000 บาท ต่อภาคการศึกษา
          ภาคปกติ 12,000 บาท
          ภาค กศ.พบ (เสาร์-อาทิตย์) 14,000 บาท
          อัตราภาค กศ.พบ มีอยู่ในตารางของทุกสาขา ไม่ได้แปลว่าสาขานี้เปิดรับภาคนั้น
          ที่มา: ประกาศค่าเทอมของคณะ
```

* **หน่วยเต็ม** "บาท ต่อภาคการศึกษา" ตรงกับหน่วยที่ตารางต้นทางใช้ (`_unit` ในไฟล์ค่าเทอม
  เขียนว่า "บาทต่อภาคการศึกษา")
* **แยกภาคปกติกับเสาร์–อาทิตย์คนละบรรทัด** จากข้อความที่หลังบ้านส่งมา ถ้ารูปแบบเปลี่ยน
  จะแสดงข้อความเดิมทั้งก้อน ไม่ใช่ข้อความที่ถูกตัดผิดที่
* **หมายเหตุที่ต้องมี** — ไฟล์ค่าเทอมระบุไว้ว่าตารางให้อัตราภาค กศ.พบ ของทุกสาขา
  แต่ไม่ได้บอกว่าสาขาไหนเปิดรับจริง · ระบบเคยตอบผิดเพราะข้อนี้มาแล้ว (ตรวจ 14 ต.ค. 2569
  พบ 9 สาขาถูกบอกผิด) การเห็นอัตราแล้วเข้าใจว่าเปิดรับจึงเป็นการสรุปเกินหลักฐาน
* **ไม่มีข้อมูล** เขียนว่า `ยังไม่มีข้อมูลค่าเทอมในระบบ` — ไม่คำนวณเอง ไม่ให้โมเดลเติม

## 2. เรื่องวันที่ของข้อมูล (ตอบข้อ "ถ้ามี")

ไฟล์ค่าเทอมฝั่งหลังบ้านมีทั้งแหล่งและวันที่

```
_source      ตารางสรุปอัตราค่าธรรมเนียมการศึกษาระดับปริญญาตรี แบบเหมาจ่าย คณะวิทยาศาสตร์ฯ
_source_url  https://acade.pnru.ac.th/files/NewWeb/Fee/001.pdf
_as_of       ข้อมูล ณ วันที่ 13 พฤศจิกายน 2568
```

แต่ **`/api/course-facts` ยังไม่ส่งสามค่านี้ออกมา** — รอบนี้ห้ามแก้หลังบ้าน หน้าเว็บจึง
แสดงเฉพาะที่มาแบบไม่มีวันที่ (`ที่มา: ประกาศค่าเทอมของคณะ` ซึ่งเป็นถ้อยคำเดียวกับที่
หลังบ้านส่งมาในช่อง `verdict` ของหน้านี้อยู่แล้ว) · **ไม่เขียนวันที่ตายตัวไว้ในหน้าเว็บ**
เพราะถ้าตารางต้นทางเปลี่ยน วันที่จะค้างผิดโดยไม่มีใครรู้

ถ้าต้องการวันที่และลิงก์ต้นทางบนหน้าเว็บ ต้องเพิ่มสามช่องนี้ใน `/course-facts` ซึ่งเป็น
งานหลังบ้านอีกรอบ (ประมาณ 5 บรรทัด) — ยังไม่ได้ทำตามที่สั่ง

## 3. ผลตรวจ (ใช้ API ของเว็บจริงแบบอ่านอย่างเดียว · ไม่เรียก AI)

เสิร์ฟหน้าเว็บที่ build แล้ว ต่อเข้ากับ `/api` ของ production (เฉพาะ GET) แล้วอ่าน DOM

| สาขา | ช่องค่าเทอมที่ได้ |
|---|---|
| การจัดการสิ่งแวดล้อมและทรัพยากรธรรมชาติ | `12,000 บาท ต่อภาคการศึกษา` · `ภาคปกติ 12,000 บาท` · `ภาค กศ.พบ (เสาร์-อาทิตย์) 14,000 บาท` · หมายเหตุ กศ.พบ · ที่มา |
| สาขาวิชาสาธารณสุขศาสตร์ | `ยังไม่มีข้อมูลค่าเทอมในระบบ` |

ตรวจกับ API ตรง ๆ ยืนยันว่าสาธารณสุขศาสตร์ไม่มีค่าเทอมในระบบจริง (`tuition_per_semester`
เป็น `null`) ไม่ใช่หน้าเว็บอ่านไม่เจอ · ลำดับแถวเป็น ปีหลักสูตร → ระยะเวลาเรียน →
**ค่าเทอม** → รายละเอียด → อาชีพ → ดูเพิ่มเติม ตามที่สั่ง
