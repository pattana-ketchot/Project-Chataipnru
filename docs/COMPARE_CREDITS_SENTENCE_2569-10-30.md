## 1. ทำไมด่านเดิมไม่พอ

ด่านรอบก่อนตรวจว่า "ตัวเลขที่สรุปพูดถึง มีอยู่ในตารางไหม" ซึ่ง**ปล่อยการสลับเลขข้าม
คอลัมน์ผ่าน** — ถ้าเทียบสิ่งแวดล้อมฯ (135) กับวิทยาการคอมพิวเตอร์ (130) แล้วโมเดลสลับ
เป็น "สิ่งแวดล้อมฯ 130" เลข 130 ก็ยังอยู่ในตาราง ด่านจึงไม่จับ

จะตรวจให้ถูกต้องต้องรู้ว่า "เลขนี้เป็นของหลักสูตรไหน" ซึ่งต้องอ่านภาษาธรรมชาติอีกชั้น
จึงเลือกทางที่ง่ายและแน่นอนกว่าตามที่สั่ง

## 2. วิธีที่ใช้

1. **ระบบเขียนประโยคหน่วยกิตเอง** จาก `verified_credit_phrases()` ผูกตัวเลขกับ
   **ชื่อหลักสูตรและปีของฉบับนั้น** ตรง ๆ แล้ววางไว้ต้นย่อหน้าสรุปเสมอ

   ```
   จำนวนหน่วยกิตรวมตลอดหลักสูตรจากเอกสารที่ตรวจแล้ว:
   หลักสูตรวิทยาศาสตรบัณฑิต สาขาวิชาการจัดการสิ่งแวดล้อมและทรัพยากรธรรมชาติ (พ.ศ. 2565) ไม่น้อยกว่า 135 หน่วยกิต ·
   หลักสูตรวิทยาศาสตรบัณฑิต สาขาวิชาวิทยาการคอมพิวเตอร์ (พ.ศ. 2566) ไม่น้อยกว่า 130 หน่วยกิต
   ```

2. **โมเดลไม่เห็นแถวหน่วยกิตอีกต่อไป** — แถวนั้นถูกตัดออกจากพรอมต์สรุป และพรอมต์
   เพิ่มกฎว่าห้ามพูดถึงจำนวนหน่วยกิต
3. **ถ้าข้อความของโมเดลมีคำว่า "หน่วยกิต" ไม่ว่ารูปแบบใด ให้ทิ้งทั้งย่อหน้า** พร้อมบันทึก
   log (`d68bf57`) — ดูทั้งคำ ไม่ใช่เฉพาะรูป "ตัวเลข + หน่วยกิต" เพราะ "หน่วยกิตรวม 130"
   (เลขอยู่หลังคำ) และ "ใช้หน่วยกิตน้อยกว่าอีกสาขา" (ไม่มีเลข) ก็ตรวจย้อนไม่ได้เหมือนกัน ·
   ประโยคหน่วยกิตของระบบยังแสดงตามปกติ ผู้ใช้จึงไม่เสียข้อมูลที่ตรวจแล้วไป
4. ฉบับที่ยังไม่มีค่าที่ตรวจแล้ว เขียนว่า **"ยังไม่มีค่าหน่วยกิตที่ตรวจแล้วในระบบ"**
   ไม่เติมและไม่ยืมของฉบับอื่น

## 3. ผลทดสอบ (โมเดลจำลอง · ข้อมูลจริงบนฐานทดสอบ · ไม่ยิงโมเดลจริง)

ทุกกรณี **พรอมต์สรุปไม่มีแถวหน่วยกิต** (ตรวจจากข้อความที่ส่งเข้าโมเดลจริง ๆ)

| กรณี | ย่อหน้าของโมเดล | สิ่งที่ผู้ใช้เห็น |
|---|---|---|
| **คู่ควบคุม สิ่งแวดล้อม 135 + วิทย์คอม 130 · โมเดลสลับเลข** ("สิ่งแวดล้อมฯ 130 · วิทย์คอม 135") | **ถูกทิ้ง** (log: `พูดถึงหน่วยกิต 130, 135 ทั้งที่ห้ามไว้`) | ประโยคของระบบเท่านั้น: สิ่งแวดล้อมฯ **135** · วิทย์คอม **130** — ข้ออ้างสลับเลขไม่ถูกแสดง |
| โมเดลพูดถึงหน่วยกิตแบบถูกต้อง | **ถูกทิ้งเช่นกัน** (ตั้งใจ — ผูกหลักสูตรแบบตรวจย้อนไม่ได้) | ประโยคของระบบเท่านั้น ซึ่งถูกต้องอยู่แล้ว |
| **โมเดลเขียน "หน่วยกิตรวม 130"** (เลขอยู่หลังคำ) | **ถูกทิ้ง** | ประโยคของระบบเท่านั้น: 135 · 130 ถูกต้อง |
| **โมเดลเปรียบเทียบลอย ๆ** ("สิ่งแวดล้อมใช้หน่วยกิตน้อยกว่าวิทย์คอม" ไม่มีเลข) | **ถูกทิ้ง** | ประโยคของระบบเท่านั้น |
| โมเดลไม่พูดถึงหน่วยกิตเลย (ทำตามพรอมต์) | แสดง | ประโยคหน่วยกิตของระบบ + ย่อหน้าของโมเดลต่อท้าย |
| ฉบับที่ไม่มีค่าที่ตรวจแล้ว (สาธารณสุขฯ) + โมเดลเติม 129 เอง | **ถูกทิ้ง** | `หลักสูตรสาธารณสุขศาสตรบัณฑิต … ยังไม่มีค่าหน่วยกิตที่ตรวจแล้วในระบบ · คณิตศาสตร์ (พ.ศ. 2569) ไม่น้อยกว่า 124 หน่วยกิต` — ไม่มีเลข 129 โผล่ |

ชุดทดสอบเดิม: `test_credit_phrase_and_sources` 16 ชุด/29 จุดตรวจ · `test_score_detail` 24 ·
`test_rationale_evidence` 8 — ผ่านทั้งหมด

**ข้อจำกัดที่เหลือ:** หัวข้ออื่นในตาราง (เรียนอะไรบ้าง ทักษะ อาชีพ คุณสมบัติ) ยังเป็นการ
สกัดด้วยโมเดลเหมือนเดิม และย่อหน้าของโมเดลยังพูดเรื่องอื่นผิดได้ · รอบนี้ปิดเฉพาะ
ข้ออ้างเชิงตัวเลขหน่วยกิตเท่านั้น
