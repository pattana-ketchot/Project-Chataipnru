## 3. แบบฟอร์มประเมินความตรงเชิงเนื้อหา (IOC) สำหรับผู้เชี่ยวชาญ

ต้องให้ **ผู้เชี่ยวชาญ 3 ท่าน** ตรวจข้อคำถามทั้ง 16 ข้อก่อนนำไปใช้จริง
(หากติดต่อไม่ทันในเวลาที่กำหนด ให้ดูหัวข้อที่ 6)

### คำชี้แจงสำหรับผู้เชี่ยวชาญ

> ขอความอนุเคราะห์พิจารณาว่าข้อคำถามแต่ละข้อสอดคล้องกับวัตถุประสงค์ของการประเมินหรือไม่
> โดยให้คะแนนดังนี้
>
> **+1** เมื่อแน่ใจว่าข้อคำถามสอดคล้องกับวัตถุประสงค์
> **0** เมื่อไม่แน่ใจว่าข้อคำถามสอดคล้องกับวัตถุประสงค์
> **−1** เมื่อแน่ใจว่าข้อคำถามไม่สอดคล้องกับวัตถุประสงค์

### ตารางให้คะแนน

| ข้อที่ | ข้อคำถาม | ผู้เชี่ยวชาญ 1 | ผู้เชี่ยวชาญ 2 | ผู้เชี่ยวชาญ 3 | ΣR | IOC | ผลการพิจารณา |
|---|---|---|---|---|---|---|---|
| 1.1 | ระบบตอบคำถามได้ตรงกับสิ่งที่ถาม | | | | | | |
| 1.2 | ข้อมูลถูกต้องน่าเชื่อถือ | | | | | | |
| … | (ครบทั้ง 16 ข้อ) | | | | | | |

### สูตรและเกณฑ์

```
        ΣR
IOC = ──────
         n

เมื่อ  ΣR = ผลรวมคะแนนของผู้เชี่ยวชาญทุกท่านในข้อนั้น
       n  = จำนวนผู้เชี่ยวชาญ (ในที่นี้คือ 3)
```

**เกณฑ์การยอมรับ** ข้อคำถามที่มีค่า IOC ตั้งแต่ **0.50 ถึง 1.00** ถือว่ามีความตรงเชิงเนื้อหา
นำไปใช้ได้ ข้อที่ได้ต่ำกว่า 0.50 ต้องปรับปรุงข้อความหรือตัดออก

**ตัวอย่าง** ข้อหนึ่งได้คะแนน +1, +1, 0 → ΣR = 2 → IOC = 2 ÷ 3 = 0.67 → **ผ่าน**

## 4. วิธีวิเคราะห์ข้อมูล

### 4.1 สถิติพื้นฐาน

| ค่าที่ต้องรายงาน | สูตรใน Google Sheets / Excel |
|---|---|
| ร้อยละ (ส่วนที่ 1) | `=COUNTIF(ช่วง,"ค่าที่นับ")/COUNT(ช่วง)*100` |
| ค่าเฉลี่ย (x̄) | `=AVERAGE(ช่วง)` |
| ส่วนเบี่ยงเบนมาตรฐาน (S.D.) | `=STDEV(ช่วง)` |

### 4.2 เกณฑ์แปลความหมายค่าเฉลี่ย

| ช่วงค่าเฉลี่ย | แปลความหมาย |
|---|---|
| 4.51 – 5.00 | พึงพอใจในระดับมากที่สุด |
| 3.51 – 4.50 | พึงพอใจในระดับมาก |
| 2.51 – 3.50 | พึงพอใจในระดับปานกลาง |
| 1.51 – 2.50 | พึงพอใจในระดับน้อย |
| 1.00 – 1.50 | พึงพอใจในระดับน้อยที่สุด |

### 4.3 ค่าความเชื่อมั่น Cronbach's Alpha

```
         k       ⎛     Σ S²ᵢ  ⎞
α =  ───────  ×  ⎜ 1 − ────── ⎟
      k − 1      ⎝      S²ₜ   ⎠

เมื่อ  k    = จำนวนข้อคำถาม (16 ข้อ)
       S²ᵢ  = ความแปรปรวนของคะแนนข้อที่ i
       S²ₜ  = ความแปรปรวนของคะแนนรวมทั้งฉบับ
```

**วิธีคำนวณใน Google Sheets**

1. จัดข้อมูลให้ **แถวคือผู้ตอบ 1 คน · คอลัมน์คือข้อคำถาม 1 ข้อ** (ได้ตาราง 30 แถว × 16 คอลัมน์)
2. เพิ่มคอลัมน์ `รวม` ท้ายสุด: `=SUM(B2:Q2)` แล้วลากลงทุกแถว
3. ใต้ตาราง คำนวณความแปรปรวนรายข้อ: `=VAR(B2:B31)` แล้วลากขวาให้ครบ 16 คอลัมน์
4. หาผลรวมความแปรปรวนรายข้อ (ΣS²ᵢ): `=SUM(ช่วงความแปรปรวน)`
5. หาความแปรปรวนของคะแนนรวม (S²ₜ): `=VAR(คอลัมน์รวม)`
6. คำนวณค่าแอลฟา: `=(16/15)*(1-ΣS²ᵢ/S²ₜ)`

**เกณฑ์การยอมรับ** ค่าแอลฟาตั้งแต่ **0.70** ขึ้นไปถือว่าเครื่องมือมีความเชื่อมั่นอยู่ในระดับที่ยอมรับได้
(0.80 ขึ้นไป = ดี · 0.90 ขึ้นไป = ดีมาก)

> **รายงานค่าที่คำนวณได้ตามจริง** แม้จะต่ำกว่า 0.70 ก็ให้รายงานพร้อมอภิปรายสาเหตุ
> เช่น จำนวนผู้ตอบยังน้อย หรือข้อคำถามบางข้อวัดคนละด้านกัน — ห้ามปรับตัวเลขให้ดูดี

## 6. ถ้าเก็บข้อมูลไม่ทันกำหนดส่ง

**ห้ามสร้างตัวเลขขึ้นมาเอง** ทั้งค่าเฉลี่ย ค่า IOC และค่าความเชื่อมั่น
เหตุผลตรงไปตรงมาคือในวันนำเสนอ กรรมการจะถามว่าเก็บจากใคร จำนวนเท่าใด เมื่อใด
และผู้เชี่ยวชาญสามท่านคือใคร หากตอบไม่ได้จะเสียหายมากกว่าการยอมรับว่ายังเก็บไม่ครบ

**ให้ทำแทน** เขียนไว้ในบทที่ 3 ว่าออกแบบเครื่องมือไว้แล้วอย่างไร (ใส่แบบสอบถามในภาคผนวกตามปกติ)
แล้วระบุในบทที่ 4 และ 5.3 ว่าการเก็บข้อมูลความพึงพอใจและการตรวจสอบคุณภาพเครื่องมือ
ยังอยู่ระหว่างดำเนินการ เป็นข้อจำกัดของโครงการในรอบนี้

เล่มฉบับ v8 เขียนทำนองนี้ไว้แล้วที่หัวข้อ 4.6.2 และ 4.7.1 — ให้คงแนวทางเดิมไว้
