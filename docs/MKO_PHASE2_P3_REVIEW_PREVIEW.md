## 1. วิธีตรวจ

1. **อ่านข้อมูลจริงจาก production แบบ read-only** — ทุก field_value / list_item / evidence / review_decision / live view ของ 5 field ที่ routing รองรับ
2. **ยืนยันว่าไฟล์ในเครื่องคือไฟล์เดียวกับที่ระบบสกัด** — SHA-256 ของ 18 ไฟล์ที่เกี่ยวข้องตรงกับ `course_documents.file_sha256` **ครบทุกไฟล์**
3. **เทียบข้อความรายข้อกับข้อความรายหน้าที่ระบบเก็บ** (`mko.document_pages.text_clean`) — ทุกข้อของทุกหน่วยพบในหน้า (ไม่นับช่องว่าง)
4. **เทียบกับภาพหน้าเอกสารจริง** — render หน้าหลักฐานเป็นภาพแล้วตรวจด้วยตา **ครบทุกหน่วยที่เสนอ VERIFIED (23 หน้า)** และอีก 3 หน้า: bio2568 admission, fs61 careers, en60 careers · ดูจุดจบรายการ (หัวข้อถัดไป) ด้วย · attm65 และ ma64 careers ใช้ผลตรวจภาพจาก P2/P1 เพราะ review key ไม่เปลี่ยน · สาธารณสุขศาสตร์เป็นไฟล์ข้อความ ตรวจกับข้อความในไฟล์
5. **สแกน glyph เพี้ยนจาก text layer** (เช่น "น้ า" แทน "น้ำ") ทุกข้อของทุกหน่วย และของรายการที่ verified แล้วทั้งหมด
6. **ตรวจความเป็นฉบับล่าสุด** ทั้งจากชื่อ+ปี และจากข้อ 6.1 ของ มคอ.2 ("ปรับปรุงจากหลักสูตร…") เพื่อจับหลักสูตรที่เปลี่ยนชื่อ
7. **คำนวณ review key ด้วยฟังก์ชันเดียวกับ `pipeline.mko.review`** (ข้อ 10)
8. ไม่ใช้คำตอบ RAG และไม่ใช้ข้อมูลของฉบับปีอื่นมายืนยัน

**กติกาเรื่องช่องว่างจากการตัดบรรทัด** (ตามแนวที่ผู้อนุมัติใช้ใน P1/P2):

### 9.3 การจัดการเทคโนโลยีการเกษตรและบริหารทรัพยากรชุมชน (ป.เอก) 2568 — admission · **VERIFIED**
- **source:** `agri68_phd.pdf` (std2565) หน้า 91 "หมวดที่ 6 คุณสมบัติของผู้เข้าศึกษา"
- **รายการ (2 ข้อ = 2 แผน):**
  1. แผน 1 (แผน 1.1 ผู้ศึกษาที่สำเร็จปริญญาโท) — ข้อย่อย 1)–7): ตามประกาศการรับนักศึกษา · สำเร็จปริญญาโทจากสถาบันที่ สป.อว. รับรอง · มีประสบการณ์วิจัย/ผลงานตีพิมพ์ระดับชาติ หรือประสบการณ์ทำงานที่เกี่ยวข้อง ≥ 3 ปี · ผลสอบภาษาอังกฤษตามประกาศ · ศึกษาได้ทั้งภาษาไทยและภาษาอังกฤษ · คุณสมบัติอื่นตามที่มหาวิทยาลัยกำหนด · นอกเหนือจากนี้อยู่ในดุลยพินิจของคณะกรรมการบริหารหลักสูตร
  2. แผน 2 (แผน 2.1 ผู้ศึกษาที่สำเร็จปริญญาโท) — ข้อย่อย 1)–6): เหมือนแผน 1 **ยกเว้นไม่มีเงื่อนไขประสบการณ์วิจัย 3 ปี**
- **ตรวจกับภาพ:** ข้อความครบทุกข้อย่อยและเรียงตามต้นฉบับ · **จุดจบ:** ถัดไปคือ "2. ปัญหาของนักศึกษาแรกเข้า"
- **ข้อควรทราบ:** ข้อย่อยถูกรวมเป็นย่อหน้าเดียวต่อแผน (784 / 692 ตัวอักษร) ยังมีเลข 1)–7) ในข้อความ อ่านแยกได้ · "ปริญญา โท" มีช่องว่างตัดบรรทัด ความหมายไม่เปลี่ยน
- **เหตุผล VERIFIED:** ไม่มีข้อความหายและไม่มีข้อความเกิน เงื่อนไขที่ต่างระหว่างแผนถูกเก็บครบ — ถ้าผู้อนุมัติต้องการให้ข้อย่อยเป็นรายการแยก ให้ KEEP_REVIEW แทน (ต้องแก้ตัวสกัด)

### 9.4 การจัดการเทคโนโลยีการเกษตรและบริหารทรัพยากรชุมชน (ป.โท) 2568 — admission · **VERIFIED**
- **source:** `agri68_master.pdf` (std2565) หน้า 85 "หมวดที่ 6 คุณสมบัติของผู้เข้าศึกษา"
- **รายการ (3 ข้อ):**
  1. ย่อหน้านำ: ให้เป็นไปตามข้อบังคับฯ ว่าด้วยการศึกษาระดับบัณฑิตศึกษา พ.ศ. 2551 และ (ฉบับที่ 3) พ.ศ. 2563 หรือระเบียบที่ปรับปรุงใหม่ "และมีคุณสมบัติเฉพาะดังนี้"
  2. แผน 1 แบบวิชาการ (วิทยานิพนธ์อย่างเดียว): 1.1.1 ป.ตรีสาขาที่เกี่ยวข้องจากสถาบันที่ อว./กพ. รับรอง · 1.1.2 ประสบการณ์ทำงาน/วิจัยที่เกี่ยวข้อง ≥ 3 ปี พร้อมหนังสือรับรอง · 1.1.3 กรณีไม่ตรงเกณฑ์อยู่ในดุลยพินิจของคณะกรรมการบริหารหลักสูตร
  3. แผน 1 แบบวิชาการ (ศึกษารายวิชาและวิทยานิพนธ์): 1.2.1 ป.ตรีสาขาที่เกี่ยวข้อง **GPA ≥ 2.50** หรือ 1.2.2 ป.ตรีสาขาอื่นที่มีประสบการณ์ที่เกี่ยวข้อง ≥ 2 ปี · 1.2.3 ดุลยพินิจคณะกรรมการ
- **ตรวจกับภาพ:** ครบทุกข้อย่อย · คำสะกด "ว่าเวย" และ "ราชภัฎ" มีในต้นฉบับจริง · **จุดจบ:** ถัดไปคือ "2. ปัญหาของนักศึกษาแรกเข้า"
- **ข้อควรทราบ:** ข้อ 1 เป็นย่อหน้านำที่ลงท้าย "ดังนี้" — ถูกเก็บไว้ (ต่างจากกรณี attm65 careers ที่ย่อหน้านำหาย) · "คณะ กรรมการ" มีช่องว่างตัดบรรทัด ความหมายไม่เปลี่ยน

### 12.5 Blocker ที่เหลือก่อนพิจารณา `STRUCTURED_ANSWERS=on`

รายการข้อเท็จจริง ไม่ได้ตั้งเกณฑ์ตัวเลขสำหรับเปิด on

1. **ยังไม่มีผล shadow ของ careers / admission / objectives หลัง publish รอบใหม่** — ตัวเทียบรายการ (4-gram coverage) ยังไม่เคยถูกวัดกับ admission ที่เป็นย่อหน้ายาว ต้องทำ Final Shadow Validation
2. **นโยบาย publish ยังเป็น `verified_any`** — live 46 ค่ายืนยันด้วยกฎอัตโนมัติ ไม่มีคนตรวจ ([publish.py](pipeline/mko/publish.py) ระบุว่า `verified_human_only` ควรใช้ก่อนแสดงผลจริง) ต้องตัดสินว่ายอมรับหรือไม่
3. **หลักสูตรที่เปลี่ยนชื่อไม่ถูกเชื่อมเป็นสายเดียวกัน** (ข้อ 5.1) — คำถามชื่อเดิมจะได้ข้อมูลฉบับเก่าที่ live อยู่ (fs61 / en60: total_credits, edition_year) โดยไม่บอกว่ามีฉบับใหม่แทน
4. **ความหมายของ admission** — เป็นเกณฑ์ใน มคอ.2 ของปีที่หลักสูตรอนุมัติ (บางฉบับ พ.ศ. 2561) ไม่ใช่ประกาศรับสมัครปีปัจจุบัน รูปแบบคำตอบต้องบอกที่มาและให้ดูประกาศรับสมัครล่าสุด (เป็นงานออกแบบคำตอบ ไม่อยู่ในขอบเขตรอบนี้)
5. **ข้อมูล live ที่มีข้อความเพี้ยน** — careers en65 "น้ า" (ข้อ 5.2) ต้องตัดสินก่อน
6. **careers ของฉบับ 2569 สามสาขาไม่มีในเอกสาร** — คำถามอาชีพของสามสาขานี้จะเป็น no_data → RAG ตลอด (ถูกต้องตามหลักไม่เดา แต่ coverage ของ field ที่ถูกถามมากที่สุดจะไม่ครบ)
7. **ค้างจากรอบก่อน:** ระดับปริญญาอ่านจากคำไทยเท่านั้น · สาขาหลายระดับที่ไม่ระบุระดับตกไป RAG · `mko.curricula.degree_level` / `edition_year_be` ยังว่าง · ตัวเทียบหน่วยกิตบัณฑิตศึกษาต้องมีคำบอกบริบทยอดรวม

### 12.6 ข้อเสนอ: หลัง P3 ควรมี P4 หรือไม่

**ข้อเสนอ: หยุด review ทั่วไปหลัง P3 แล้วทำ Final Shadow Validation — ไม่แนะนำ P4 แบบกวาดทั้งคลัง**

เหตุผล:
- หลัง P3 ฉบับล่าสุดมี coverage 83% และช่องว่างที่เหลือส่วนใหญ่ **review แก้ไม่ได้** (ต้องมีเอกสารหรือแก้ตัวสกัด)
- สิ่งที่ P4 จะได้คือรายการของ **ฉบับเก่า** 17 หน่วย + fs61/en60 — backend ใช้ฉบับล่าสุดที่มีข้อมูลก่อน จึงแทบไม่เปลี่ยนคำตอบ และเพิ่มความเสี่ยงแสดงข้อมูลฉบับที่ถูกแทน
- blocker ที่เหลือ (ข้อ 12.5) เป็นเรื่อง **นโยบายและการออกแบบคำตอบ** มากกว่าข้อมูล — ต้องมีหลักฐานจาก shadow ก่อนตัดสิน

ลำดับที่เสนอ (แต่ละขั้นต้องขออนุมัติแยก):
1. ตัดสิน P3 (ทั้งหมดหรือบางกลุ่ม) → apply → publish
2. ตัดสินข้อค้นพบ 5.1 (ฉบับถูกแทน) และ 5.2 (en65 "น้ า")
3. **Final Shadow Validation** ครอบคลุม careers / admission / objectives / edition_year ของฉบับล่าสุด รวมกรณี no_data และชื่อหลักสูตรเดิม
4. ใช้ผล shadow ตัดสิน blocker 12.5 ข้อ 2–4 ก่อนพิจารณา on
5. P4 เฉพาะจุดเท่านั้น ถ้า shadow ชี้ว่าจำเป็น (เช่น ผู้ใช้ถามถึงฉบับเก่าจริง)
