## 4. เรื่องชื่อโมเดลหาย — **ยังทำซ้ำไม่ได้ จึงยังไม่ปิด**

ทดสอบด้วยสาขาชุดเดียวกับภาพ (การจัดการสิ่งแวดล้อมฯ · คอมพิวเตอร์แอนิเมชันฯ ·
คณิตศาสตร์ · เทคโนโลยีการเกษตรสมัยใหม่) และเก็บ **response กับ DOM ของคำขอเดียวกัน**
โดยดัก `fetch` ไว้ก่อนกดปุ่ม ไม่ได้ยิงคนละคำขอมาเทียบกัน

```

สถานะของคำขอ          : 200
engine ใน response     : {"explanation": {"provider": "gemini", "model": "gemini-3.5-flash-lite"},
                          "scoring": null}
บรรทัดบนหน้าจอ        : "คำอธิบายโดย Gemini · gemini-3.5-flash-lite"
สถานะปุ่มตอนอ่าน DOM  : "วิเคราะห์อีกครั้ง"  (ตรงกับภาพ คือหลังได้ผลแล้ว)
```

**ชื่อรุ่นแสดงตามปกติ ทำซ้ำอาการไม่ได้** · ไม่ได้แก้โค้ดใดเพราะยังไม่รู้สาเหตุ

### ข้อสังเกตที่อาจอธิบายภาพนั้นได้ (ยังไม่ยืนยัน)

bundle ที่ production เสิร์ฟ **ก่อน 09:00:45 ของวันนี้** คือ `index-Dr0BBWtp.js`
ซึ่งตรวจแล้ว **ไม่มีสตริง `คำอธิบายโดย` เลย** (0 แห่ง) ส่วนสองตัวหลังมี

```
index-Dr0BBWtp.js   (ใช้อยู่ก่อน 09:00)   พบ "คำอธิบายโดย" 0 แห่ง
index-BndauWSW.js   (09:00 - 10:19)      พบ 1 แห่ง
index-CoOuVz20.js   (ตั้งแต่ 10:19)      พบ 1 แห่ง
```

แท็บที่เปิดค้างไว้ตั้งแต่ก่อน 09:00 แล้วไม่ได้โหลดหน้าใหม่ จะยังรันไฟล์เก่าอยู่
กดปุ่มวิเคราะห์ซ้ำได้ผลใหม่ แต่ไม่มีบรรทัดชื่อรุ่น — ตรงกับอาการในภาพ
(`index.html` ตั้ง `Cache-Control: no-cache` การโหลดหน้าใหม่จึงได้ไฟล์ล่าสุดเสมอ)

**ยืนยันไม่ได้จากฝั่งผม** เพราะไม่รู้ว่าหน้าในภาพโหลด bundle ตัวไหน · ถ้าเจออีก
รบกวนส่งสองอย่างนี้มา แล้วผมตามต่อได้ตรงตัว

1. ชื่อไฟล์ js ที่หน้านั้นโหลด (DevTools → Network → ไฟล์ `index-*.js`)
2. เวลาที่กดปุ่ม เพื่อให้ผมหา response ของคำขอนั้นใน log
