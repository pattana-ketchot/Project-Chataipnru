## 2. หลังบ้านเปลี่ยนอะไร

`/course-facts` ส่งเพิ่มสองช่องจากค่าที่มีอยู่แล้ว ไม่ได้คำนวณใหม่

```json
"edition_title": "หลักสูตรวิทยาศาสตรบัณฑิต สาขาวิชาคณิตศาสตร์ (พ.ศ. 2564)",
"edition_year": "2564"
```

ไม่แตะเนื้อหาเดิมของช่องอื่น และไม่แตะเส้นทางอื่นเลย (34 บรรทัดใน diff รวมหมายเหตุ)

## 3. เรื่องที่ต้องรู้ก่อนปล่อย — กล่องตารางเลื่อนในตัวเองแล้ว

การตรึงหัวตารางทำไม่ได้ถ้ากล่องเลื่อนเฉพาะแนวนอน เพราะ `sticky` ยึดกับกล่องที่เลื่อน
กล่องตารางจึงเปลี่ยนเป็น `max-h-[78vh] overflow-auto` คือ **เลื่อนทั้งสองแกนในกล่องตัวเอง**
ผลที่ตามมาคือหน้าจะมีแถบเลื่อนของตารางแยกจากแถบเลื่อนของหน้า ซึ่งเป็นพฤติกรรมที่
เปลี่ยนไปจากเดิม (เดิมตารางยาวเท่าไรหน้าก็ยาวตาม)

อีกจุดที่แก้พร้อมกัน: พื้นหลังหัวคอลัมน์ซ้ายเดิมเป็นสีโปร่ง `bg-pnru/10` เมื่อหัวตรึงแล้ว
แถวที่เลื่อนผ่านจะมองทะลุขึ้นมาเห็นเป็นตัวหนังสือซ้อนกัน จึงเปลี่ยนเป็นสีทึบ `#E8F5F1`
ซึ่งเป็นสีเดียวกันในทางสายตา

มุมมองการ์ด (จอแคบกว่า 768px) ใช้ `comparisonRows` ชุดเดียวกัน จึงได้แถวใหม่ทั้งสาม
โดยอัตโนมัติ และไม่มีการตรึงหัว เพราะเป็นการ์ดเรียงลงมาไม่ใช่ตาราง

## 4. ผลตรวจ (ข้อมูลจำลอง ไม่เรียกโมเดล ไม่แตะ production)

เสิร์ฟหน้าเว็บที่ build แล้วด้วยสตั๊บที่คืนสามสาขา: มีข้อมูลครบ · มีอาชีพเก้ารายการ ·
ไม่มีข้อมูลเสริมเลย แล้วอ่าน DOM จริง

| ข้อตรวจ | ผล |
|---|---|
| แถวในตาราง | `ปีหลักสูตรและแหล่งอ้างอิง` · `ระยะเวลาเรียน` · `รายละเอียดหลักสูตร` · `อาชีพที่สามารถทำได้` · `ดูเพิ่มเติม` |
| ปีฉบับ/แหล่งอ้างอิง | สาขาหนึ่งได้ `ฉบับ พ.ศ. 2564 / ma64.pdf` อีกสาขาได้ `ฉบับ พ.ศ. 2569 / anim69.pdf` ไม่ปนกัน |
| สาขาที่ไม่มีข้อมูล | ขึ้น `ยังไม่มีข้อมูลฉบับหลักสูตรในระบบ` · `ยังไม่มีข้อมูลในระบบ` · `ยังไม่มีเอกสารให้เปิด` |
| ย่อรายการอาชีพ | สาขาที่มี 9 อาชีพแสดง 5 รายการ + ปุ่ม `ดูทั้งหมด (9)` · กดแล้วครบ 9 และปุ่มเป็น `ย่อรายการ` |
| ปุ่มลัด | ทั้งสามปุ่มขึ้นครบทุกคอลัมน์ · ดูเอกสารเลือกเล่มเต็มไม่ใช่ฉบับย่อ |
| ตรึงหัวตาราง | `position: sticky` · เลื่อนในกล่อง 430px แล้วขอบบนของหัวอยู่ที่เดิม (ต่างกัน < 2px) |
| หัวตารางทึบ | `rgb(232, 245, 241)` · ไม่มีตัวหนังสือของแถวที่เลื่อนผ่านทะลุขึ้นมา |

ยังไม่ได้ตรวจกับข้อมูลจริงบนเซิร์ฟเวอร์ เพราะ `/course-facts` ยังไม่ได้ปล่อยช่อง
`edition_year` ขึ้นไป — ถ้าอนุมัติจะปล่อย backend ก่อนแล้วตรวจรับหน้าเว็บจริงตามปกติ
