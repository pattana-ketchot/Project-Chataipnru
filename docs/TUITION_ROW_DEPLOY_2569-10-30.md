## 2. ตรวจรับบนเว็บจริง (bundle ที่หน้านั้นโหลด: `index-CgjJtycq.js`)

### 2.1 แถวค่าเทอมตรงกับ API

| | หน้าเว็บ | API (`/course-facts`) |
|---|---|---|
| การจัดการสิ่งแวดล้อมฯ | `12,000 บาท ต่อภาคการศึกษา` · `ภาคปกติ 12,000 บาท` · `ภาค กศ.พบ (เสาร์-อาทิตย์) 14,000 บาท` | `tuition_per_semester = 12,000 บาท` · `study_format = ภาคปกติ 12,000 บาท · ภาค กศ.พบ (เสาร์-อาทิตย์) 14,000 บาท` |
| สาขาวิชาสาธารณสุขศาสตร์ | `ยังไม่มีข้อมูลค่าเทอมในระบบ` | `tuition_per_semester = null` |

* หน่วยเขียนว่า **"บาท ต่อภาคการศึกษา"** ครบ
* แยกภาคปกติกับภาค กศ.พบ คนละบรรทัด
* มีหมายเหตุ `อัตราภาค กศ.พบ มีอยู่ในตารางของทุกสาขา ไม่ได้แปลว่าสาขานี้เปิดรับภาคนั้น`
* มีที่มา `ที่มา: ประกาศค่าเทอมของคณะ`
* **กรณีไม่มีข้อมูลไม่เติมราคาใด ๆ** และตรวจกับ API ยืนยันว่าไม่มีจริง ไม่ใช่หน้าเว็บอ่านไม่เจอ

### 2.2 ของเดิมยังอยู่ครบ

| ข้อตรวจ | ผล |
