## 2. ตรวจรับบนเว็บจริง (bundle `index-DwOOxvle.js`)

### 2.1 Hero เป็นแบบที่เลือก

| ข้อตรวจ | ผล |
|---|---|
| ชั้นสีพื้นหลัง | ม่านสองชั้น (จอแคบ/จอกว้าง) + สีรองพื้นกรอบข้อความ **ครบ** |
| หัวข้อ (จอ 1440) | 52px · น้ำหนัก 600 · ระยะบรรทัด 64.48px (1.24) |
| ชื่อมหาวิทยาลัย | ตัวพิมพ์ใหญ่ + ขีดสีเขียวเหนือบรรทัด |
| ปุ่ม | พื้นสีเดียว `rgb(1, 106, 43)` |
| การเลื่อนแนวนอน | 0 ทั้งที่ 1440 และ 375 |

ภาพหน้าเว็บจริง: [เดสก์ท็อป](raw/hero-live-desktop.jpg) · [มือถือ](raw/hero-live-mobile.jpg)
