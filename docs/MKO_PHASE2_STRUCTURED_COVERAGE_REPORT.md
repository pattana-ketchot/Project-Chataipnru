  - ระบุปี → ใช้เฉพาะฉบับนั้น
  - ค่าเดี่ยวที่ต่างกันระหว่างฉบับ → แยกบรรทัดตามชื่อฉบับ
  - รายการ → แสดงฉบับล่าสุดที่มีข้อมูลและบอกชื่อฉบับอื่น
  - ฉบับที่ไม่มีข้อมูลถูกระบุชื่อ
- **ตัวอย่างจริงใน shadow:** "หลักสูตรเทคโนโลยีสารสนเทศเรียนกี่หน่วยกิต" ได้ 2566: 130 / 2561: 127 แยกบรรทัด (agree)

**ความเสี่ยงที่ยังเหลือ:**
1. **ไม่มีตัวตนของ "ฉบับ" ในระดับฐานข้อมูล**
   - `mko.programs` ว่าง และ `curricula.program_id` / `edition_year_be` เป็น NULL
   - UNIQUE `(program_id, edition_year_be)` จึงไม่มีผลจริง การแยกฉบับอาศัย "1 course = 1 ฉบับ" และปีในชื่อหลักสูตร
2. **ฉบับที่ไม่มีปี** (สาธารณสุขศาสตร์: ชื่อหลักสูตรและเอกสารไม่มีปี)
   - คำถามที่ระบุปีจะไม่ตรงฉบับใดเลย
   - ถ้าเพิ่มฉบับที่สองในอนาคตจะแยกไม่ได้
3. **รายการถอยไปใช้ฉบับเก่าเมื่อฉบับใหม่ไม่มีข้อมูล**
   - เช่น ถ้า careers ของคณิตศาสตร์ 2564 ผ่านการตรวจ คำถาม "คณิตศาสตร์จบไปทำอาชีพอะไร" จะได้รายการของฉบับ 2564 พร้อมแจ้งว่า 2569 ยังไม่มีข้อมูล (เอกสาร 2569 ไม่มีหัวข้อนี้)
   - มีป้ายชื่อฉบับกำกับ ไม่ได้ปน แต่เป็นเรื่องที่ต้องตัดสินว่ายอมรับให้แสดงอาชีพของฉบับเก่าหรือไม่
4. **ป.โท / ป.เอก ชื่อสาขาเดียวกันปีเดียวกัน** — คำถามที่ไม่ระบุระดับจะได้ทั้งสองฉบับแยกบรรทัด ไม่ได้ทดสอบกรณีที่ผู้ใช้ระบุ "ปริญญาโท" ในรอบนี้ (วิเคราะห์อย่างเดียว)
5. **ค่าที่ต่างกันระหว่างฉบับ** (หน่วยกิต 3 สาขา, จำนวนข้อรายการ 7 คู่) — ถ้ามีจุดใดรวมหรือเลือกค่าข้ามฉบับในอนาคต จะเกิดคำตอบผิดทันที ต้องคงการแยกตาม course_id ไว้
