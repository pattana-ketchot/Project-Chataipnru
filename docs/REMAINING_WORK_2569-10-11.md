## B. ขั้นตอน deploy M3 — ทำต่อเนื่องได้เมื่ออนุมัติ A1

ยืนยันสภาพ production เมื่อ 11 ต.ค. 2569

|---|---|
| B1. สำรองฐานข้อมูล + `.env` + compose + `api/` | ยังไม่ทำ |

| B7. ส่ง `docker-compose.prod.yml` ตัวใหม่ | **ยังไม่มีส่วนของ M3 เลย** (`WEBAPI_DB_USER` นับได้ 0) |

### กับดักที่อันตรายที่สุดของ deploy รอบนี้

ถ้าส่งแต่โค้ดแล้วลืม compose — **คอนเทนเนอร์จะขึ้นปกติ `/healthz` ตอบ `status: ok`** แต่การเชื่อมตัวตนไม่ทำงานเลย โดยไม่มีอะไรฟ้อง

และ `/healthz` **พิสูจน์การเชื่อมต่อฐานข้อมูลไม่ได้** — `dbConfigured: true` แปลว่า "มีค่า env ครบ" เท่านั้น ไม่ได้แปลว่ารหัสผ่านถูก จึงเพิ่มขั้นตรวจการเชื่อมต่อจริงไว้ใน runbook ข้อ 4.0 **ห้ามข้าม**
