## 4. ข้อจำกัดที่ยังอยู่

* **ป้ายบอกได้แค่ "รุ่นไหนทำงานให้คำขอนี้" ไม่ใช่ "รุ่นไหนเขียนบรรทัดไหน"** — ระบบไม่ได้
  ตามรอยว่าคำตอบแต่ละครั้งถูกนำไปแสดงหรือถูกตัดทิ้งที่ด่านตรวจข้อความอ้างอิง ถ้าต้องการ
  ความละเอียดระดับนั้นต้องเพิ่มกลไกตามรอย ซึ่งรอบนี้ไม่ได้ทำตามที่สั่ง
* ตารางเปรียบเทียบยังเป็นผลจากการให้โมเดลสกัดจากเอกสาร ไม่ใช่ข้อความที่พิมพ์อยู่ใน
  เอกสารตรง ๆ (บอกไว้บนหน้าแล้ว) · ค่าเทอมมาจากประกาศของคณะ ไม่ผ่านโมเดล
* commit หน้าเว็บยัง push ขึ้น GitHub ไม่ได้ (สิทธิ์) — มี `git bundle` ที่ clone กลับมา
  ทดสอบแล้ว แต่ยังไม่มีสำเนานอกเครื่อง
* เรื่อง "ชื่อโมเดลหาย" ที่เคยเจอในหน้าเปรียบเทียบ ยังทำซ้ำไม่ได้ และยังรอชื่อไฟล์ js
  กับเวลาที่กดปุ่ม
