## 2. ด่านตรวจที่เพิ่ม

`_summarise()` ตรวจย่อหน้าที่โมเดลเขียน: ดึงตัวเลขทุกตัวที่ตามด้วยคำว่า "หน่วยกิต"
ถ้ามีตัวใด **ไม่ปรากฏในตารางที่ส่งให้โมเดลเลย** ให้ทิ้งย่อหน้าสรุปทั้งย่อหน้าและบันทึก log

```
WARNING ทิ้งย่อหน้าสรุป: อ้างหน่วยกิต 130 ซึ่งไม่มีในตาราง — '…ไม่น้อยกว่า 130 หน่วยกิต…'
```

หน้าเว็บไม่แสดงย่อหน้าสรุปเมื่อค่าว่างอยู่แล้ว ตารางที่ตรวจแล้วยังอยู่ครบ — เลือกทิ้ง
ทั้งย่อหน้าแทนการตัดเฉพาะประโยค เพราะข้อความภาษาไทยไม่มีเครื่องหมายจบประโยคที่
ตัดได้แน่นอน การตัดผิดจุดจะเหลือข้อความที่อ่านแล้วเข้าใจผิดได้อีกแบบ

**ขอบเขตของด่านนี้ (พูดให้ตรง):** จับได้เฉพาะ "ตัวเลขหน่วยกิตที่ไม่มีอยู่ในตาราง"
· **ยังไม่จับ** การสลับเลขข้ามคอลัมน์ (เช่นพูดว่าคณิตศาสตร์ 135 ทั้งที่ 135 เป็นของ
สิ่งแวดล้อมฯ) เพราะต้องผูกตัวเลขเข้ากับชื่อหลักสูตรในประโยค ซึ่งเป็นงานคนละขนาด
